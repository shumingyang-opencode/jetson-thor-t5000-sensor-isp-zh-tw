HSB 多感測器

Thor 的 Holoscan Sensor Bridge 支援「感測器走乙太網路」——多顆感測器（甚至分佈在不同位置）的資料匯流進 GPU，適合機器人多感測器融合。

多感測器→HSB（乙太網路）→Holoscan→GPU 即時處理
HSB 重點：① 頻寬規劃（25GbE）② 每顆感測器的時序同步 ③ host 端解包與格式匹配。

完整案例：Thor 上接一顆 OV9281

  1. 感測器走 MIPI（近距離）或 HSB（遠距離）。
  2. 確認 I2C 通、讀到 ID、argus/Holoscan 出圖。
  3. 確認 AE/AWB 自動收斂。
  4. RAW 分析（黑位、雜訊、缺陷像素）。
  5. NVIDIA 工具做 LSC / 色彩基準。
  6. 不同場景回歸。

⚠️ Thor 具體 SDK/工具以 NVIDIA 最新文件為準。

最佳實踐

  • 固定測試場景，量化比較。
  • 讓 NVIDIA 自動化收斂，只干預異常。
  • 多感測器逐顆驗證、逐顆獨立 LSC。
  • 記錄每次改動與前後圖。
