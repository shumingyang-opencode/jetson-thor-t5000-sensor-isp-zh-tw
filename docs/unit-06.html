HSB 除錯重點

HSB 三步：① 乙太網路連線與頻寬（25GbE）② 感測器端與 host 端格式匹配 ③ I2C 橋接通道。先確認「感測器資料有進 GPU」再談畫質。

Bring-up 決策樹

「取不到感測器資料」決策樹
1. dmesg 有感測器/tegra probe？
   ├─ error → DTB / 電源
   └─ ok ─┐
2. (HSB) 乙太網路連通？橋接通？
   ├─ 否 → 網路 / 橋接
   └─ 是 ─┐
3. i2cdetect 讀到感測器 ID？
   ├─ 否 → I2C / 位址
   └─ 是 ─┐
4. argus/Holoscan 出圖 → ✅
看完這單元你應該能說出：
  • Bring-up 四件事。
  • HSB 除錯三步。
  • 照決策樹排解。
  • 「資料進 GPU」驗證。
